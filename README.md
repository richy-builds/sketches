# Sketches

Small single-file browser experiments. Open any `index.html` directly, or serve the folder.

- `seed-to-tree/` — *Becoming*: a seed becomes a leafy tree over 26 seconds, drawn entirely with code. No packages, images, fonts or network requests.
- `emotions/` — *Atlas of Feeling* (`index.html`) and *Feeling Space* (`space.html`): two interactive emotion-map visualisations.
